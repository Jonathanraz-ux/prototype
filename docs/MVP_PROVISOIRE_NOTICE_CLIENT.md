# Notice client — Internet Bôjô pour tous (version provisoire)

Cette notice explique le fonctionnement du service pendant la phase
provisoire, jusqu'à l'installation du contrôle réseau définitif
(routeur MikroTik). Elle est destinée aux comptes pilotes.

## 1. Comment accéder à Internet

1. Ouvrez l'application **Bôjô** et connectez-vous.
2. Depuis l'**Accueil**, touchez **« Regarder la pub et se connecter »** :
   une publicité de 15 secondes s'affiche.
3. Dès qu'elle est terminée, votre session démarre : vous pouvez **naviguer**
   avec le navigateur intégré (raccourci Google, adresse ou recherche).
4. Tant que votre session est active, une **bannière publicitaire persiste**
   sur l'écran : c'est elle qui finance votre accès.

## 2. La navigation Bôjô est contrôlée

- La navigation intégrée ne fonctionne que lorsque la **session est active**
  et la **publicité affichée**.
- Si la session est en pause, en attente, ou si le quota est épuisé, la
  navigation est **suspendue** (écran violet) jusqu'au retour à l'Accueil.
- La navigation ne fonctionne que sur le **Wi-Fi** : en données mobiles, elle
  est suspendue pour préserver votre forfait.

## 3. Votre quota

- Bôjô vous offre un quota de **5 Go**.
- **Important (phase provisoire)** : la mesure de votre consommation sera
  effectuée par le **routeur** lors de la phase définitive. Tant que le
  comptage routeur n'est pas actif, les compteurs ne sont pas affichés à
  l'écran plutôt que d'afficher des chiffres approximatifs.

## 4. Ce que le téléphone ne fait pas (transparence)

- Bôjô **ne remplace pas** votre box ni le point d'accès Wi-Fi : le contrôle
  du réseau est un **contrôle applicatif** (navigation intégrée).
- Le mode « blocage local » affecte uniquement les autres applications du
  téléphone dans la démonstration, pas le Wi-Fi lui-même.

## 5. En cas de problème

- **Navigation coupée** : revenez à l'Accueil ; si la pub/session le permet,
  reprenez « Regarder la pub et se connecter ».
- **Quota épuisé** : le quota n'est pas renouvelable automatiquement —
  contactez un administrateur.
- **Erreur de page** : vérifiez votre connexion Wi-Fi puis réessayez.

## 6. Signature
